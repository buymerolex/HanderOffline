# HANDER (Android) - Phase 1

1. Unzip this folder.
2. Android Studio > File > Open > choose the HANDER folder (the one containing settings.gradle.kts).
3. Wait for "Gradle sync" to finish (first time downloads Gradle + libraries; needs internet).
4. Plug in your phone (USB debugging on) and press the green Run button.
5. APK: Build > Build Bundle(s) / APK(s) > Build APK(s).
   Output: app/build/outputs/apk/debug/app-debug.apk
